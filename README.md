# Java Mini Games Project
This project is a collection of interactive mini games developed in Java.
## Features
- Main menu page for selecting games
- Three different mini games:
  - Beach Ball Game
  - Paint Fight Game
  - King Yard Game
- Interactive gameplay and user-friendly interface
## About
The project starts with a main page where users can choose which game they want to play. 
Each game offers a different experience along with interesting sound effects and background music to make gameplay more enjoyable.
## Technologies Used
- Java
- Java GUI
- Audio Integration
 # Purpose
 This projects was developed to explore Java programming concepts, GUI development,
 and multimedia integration  in an interactive gaming application
